Random Typing Speed Test

1. Project Description

The Random Typing Speed Test is a simple C programming project designed to measure a user's typing speed and accuracy.

The program randomly selects 10 words from a predefined word list and displays them on the screen. The user has to type those words in the same order. After pressing Enter, the program calculates the time taken, typing speed, and estimated accuracy.

2. Features

- Generates 10 random words for every test.
- Allows users to type the displayed words.
- Measures the time taken to complete the typing task.
- Calculates typing speed in Words Per Minute (WPM).
- Estimates typing accuracy.
- Displays a performance message based on accuracy.

3. Technologies Used

- Programming Language: C
- Header Files: "stdio.h", "string.h", "stdlib.h", "time.h"
- Compiler: GCC or any compatible C compiler.

4. Concepts Used

- Variables and data types
- Arrays and strings
- Loops and conditional statements
- Random number generation
- String handling functions
- Time measurement functions
- Input and output operations

5. How the Program Works

1. The program starts by displaying its title.
2. It selects 10 random words from the word list.
3. The selected words are displayed on the screen.
4. The user types the words in the same order.
5. The program records the starting and ending time.
6. It calculates typing speed and estimated accuracy.
7. Finally, it displays the user's results.

6. Output

The program displays:

- Time Taken
- Words Typed
- Typing Speed (WPM)
- Accuracy (%)
- Performance Result

The performance message can be:

- EXCELLENT!
- GOOD!
- KEEP PRACTICING!

7. How to Run

1. Open the C source file in a C compiler or IDE.
2. Compile the program.
3. Run the executable.
4. Type the randomly displayed words.
5. Press Enter to see your results.

8. Conclusion

This project demonstrates the practical use of basic C programming concepts to develop an interactive application. It helps users understand random number generation, string manipulation, loops, conditional statements, and time calculations.
